# ETAPA 6.12 — Performance, Qualidade e OEE

O Dashboard passa a consolidar os três componentes do OEE:

- Disponibilidade: tempo disponível / tempo planejado (base da ETAPA 6.11).
- Performance: produção real / produção teórica no tempo disponível, usando o Takt configurado; limitada a 100% no OEE.
- Qualidade: leituras VALID / total de leituras no período, usada como proxy objetivo de qualidade de rastreabilidade enquanto não há estação física de inspeção de qualidade.
- OEE: Disponibilidade × Performance × Qualidade.

A informação de etapa permanece somente no botão de ajuda `?`.
Nenhuma migration nova é necessária.
