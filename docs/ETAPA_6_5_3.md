# ETAPA 6.5.3 — estabilidade da interface móvel

- Corrige a oscilação visual observada durante uso no celular.
- Em telas até 980 px o menu não reage a touch/pointer/teclado: abre e fecha somente pelo hambúrguer.
- O menu móvel é um overlay e não desloca o conteúdo da página.
- O menu inicia fechado no celular.
- No desktop permanece o comportamento de auto-ocultar após 5 segundos.
