# Ajuste de interface — etapa apenas no botão de ajuda

A interface não exibe mais o número/nome da etapa dentro das telas operacionais.

A informação de progresso da implementação permanece somente no botão `?` do cabeçalho.

Removido da interface:
- marcador `ETAPA 6.11` no card de eficiência;
- rodapé de etapa da Dashboard;
- rodapé de etapa da tela Jornada e Paradas.

Nenhuma regra de negócio, API, banco de dados ou migration foi alterada.
